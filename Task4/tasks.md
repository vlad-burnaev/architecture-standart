# Список крупных задач для систем MVP открытия депозитов

## АБС (Автоматизированная банковская система)

### Задачи для модуля управления ставками
1. **Разработка модуля управления ставками в АБС**
   - Создание таблиц для хранения ставок по депозитам
   - Разработка PL-SQL процедур для создания, обновления и получения ставок
   - Реализация интерфейса в десктопном клиенте для управления ставками
   - Интеграция с разделом кредитования для расчета ставок на основе кредитного риска

2. **Разработка сервиса интеграции депозитов АБС**
   - Создание REST API для получения ставок (для системы кол-центра)
   - Разработка механизма формирования файлов со ставками (CSV/JSON)
   - Реализация логики загрузки файлов на SFTP-сервер
   - Настройка кэширования ставок для оптимизации производительности
   - Реализация событийной синхронизации при изменении ставок

3. **Интеграция с интернет-банком через очередь**
   - Разработка обработчика очереди для чтения заявок из MS SQL Service Broker
   - Реализация логики обработки заявок на депозиты
   - Интеграция с модулем управления ставками для расчета ставок по заявкам
   - Реализация отправки уведомлений в сервис депозитов интернет-банка

### Задачи для API АБС
4. **Расширение API АБС**
   - Добавление endpoints для получения данных клиента (баланс, история)
   - Реализация endpoints для получения ставок по депозитам
   - Настройка аутентификации и авторизации для внешних систем
   - Документирование API

## Интернет-банк

### Задачи для сервиса депозитов
1. **Разработка сервиса депозитов (ASP.NET Core)**
   - Создание API для обработки заявок на депозиты
   - Интеграция с сервисом ставок для получения актуальных ставок
   - Реализация логики создания заявок и отправки в очередь
   - Интеграция с сервисом СМС для отправки кодов подтверждения
   - Реализация получения уведомлений от АБС о статусе заявок

2. **Разработка сервиса ставок (ASP.NET Core)**
   - Создание API для получения ставок по депозитам
   - Реализация кэширования ставок в MS SQL Server
   - Разработка механизма синхронизации с АБС
   - Реализация расчета персонализированных ставок на основе данных клиента

3. **Разработка сервиса СМС (ASP.NET Core)**
   - Создание API для отправки СМС-кодов подтверждения
   - Интеграция с СМС-шлюзом телеком-оператора
   - Реализация логики генерации и валидации СМС-кодов

### Задачи для веб-приложения
4. **Доработка веб-приложения (ASP.NET MVC 4.5)**
   - Разработка UI для просмотра депозитов и ставок
   - Реализация формы подачи заявки на депозит
   - Интеграция с сервисом депозитов, сервисом ставок и сервисом СМС
   - Реализация отображения персонализированных ставок

### Задачи для инфраструктуры
5. **Настройка очереди сообщений (MS SQL Service Broker)**
   - Создание очереди для заявок на депозиты
   - Настройка сервисов для обработки сообщений
   - Реализация механизма обработки ошибок и повторных попыток

6. **Настройка базы данных (MS SQL Server)**
   - Создание схемы для хранения заявок
   - Создание таблиц для кэширования ставок
   - Настройка индексов для оптимизации производительности
   - Настройка репликации между ЦОД

## Система кол-центра

### Задачи для интеграции со ставками
1. **Интеграция с сервисом интеграции депозитов АБС**
   - Разработка REST клиента для получения ставок
   - Реализация кэширования ставок в системе кол-центра
   - Разработка UI для отображения ставок менеджерам
   - Реализация механизма обновления ставок

2. **Доработка интерфейса для консультирования**
   - Добавление раздела со ставками по депозитам
   - Реализация поиска и фильтрации депозитов
   - Интеграция с существующим функционалом обработки заявок

## Сайт

### Задачи для отображения депозитов
1. **Интеграция с системой кол-центра**
   - Реализация передачи заявок в систему кол-центра через API
   - Настройка шифрования данных (TLS 1.3)
   - Реализация формы подачи заявки на депозит

2. **Отображение ставок**
   - Интеграция с сервисом ставок интернет-банка или АБС
   - Реализация отображения списка депозитов с актуальными ставками

## SFTP-сервер

### Задачи для развертывания и настройки
1. **Развертывание SFTP-сервера**
   - Установка и настройка SFTP-сервера (OpenSSH или специализированный)
   - Настройка пользователей и прав доступа
   - Настройка ограничения доступа по IP-адресам партнёра
   - Настройка SSH ключей для аутентификации

2. **Настройка безопасности**
   - Настройка шифрования соединений
   - Настройка логирования и мониторинга
   - Настройка резервного копирования
   - Документирование процесса обмена файлами
